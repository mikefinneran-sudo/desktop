# Clip to Research

Temporary/Phase B Zen mod that captures the active selection and posts it to `http://127.0.0.1:8787/clip`. The helper writes a Markdown file with YAML frontmatter into `~/Desktop/Daily Working Files/Research/`.

## Manual Install

1. Start the local helper.
2. Open `about:debugging#/runtime/this-firefox` in Zen.
3. Click "Load Temporary Add-on".
4. Select `walterfetch/mods/clip-to-research/manifest.json`.

Use the toolbar button, context menu item, or `Alt+Shift+C`.
